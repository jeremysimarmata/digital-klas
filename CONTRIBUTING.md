# Panduan Kontribusi

## Aturan branch
- `main`: versi utama yang sudah diperiksa.
- `feature/nama-fitur`: pengembangan fitur.
- `fix/nama-bug`: perbaikan bug.

## Alur kontribusi
1. Buat atau pilih GitHub Issue.
2. Buat branch dari `main`.
3. Ubah file HTML, CSS, atau JavaScript sesuai tugas.
4. Buka `index.html` di browser dan uji perubahan.
5. Push branch ke GitHub.
6. Buat Pull Request dan tautkan Issue dengan `Closes #nomor-issue`.
7. Minta review dari Tester.
8. Perbaiki masukan reviewer.
9. Merge hanya setelah pemeriksaan dan persetujuan selesai.

## Contoh commit
- `feat: add KRS selection form`
- `fix: validate empty course selection`
- `docs: update HTML run instructions`

Jangan unggah password, token, atau data mahasiswa sungguhan.
