# Menjalankan Aplikasi HTML

Aplikasi sekarang menggunakan HTML, CSS, dan JavaScript murni. PHP, Composer, dan database tidak diperlukan untuk menjalankan demo ini.

## Cara menjalankan
1. Buka folder repository.
2. Klik dua kali file `index.html`, atau klik kanan lalu pilih browser.
3. Pilih beberapa mata kuliah.
4. Tekan tombol **Validasi Pengajuan KRS**.
5. Coba juga mengirim tanpa memilih mata kuliah untuk melihat pesan validasi.

## Catatan
- Data mata kuliah tersimpan di dalam JavaScript pada file `index.html`.
- Validasi dilakukan di browser.
- Data tidak dikirim atau disimpan ke server/database.
- Ini cocok untuk simulasi antarmuka dan kolaborasi GitHub, bukan aplikasi akademik produksi.
