# Checklist Kesiapan Deployment

Proyek ini belum terhubung ke cloud server sungguhan.

- [ ] Pull Request disetujui.
- [ ] GitHub Actions berhasil.
- [ ] Pengujian otomatis berhasil.
- [ ] Konfigurasi produksi ditinjau.
- [ ] Secret disimpan di GitHub Actions Secrets atau secret manager.
- [ ] Backup dan prosedur pemulihan disiapkan.
- [ ] Rencana rollback tersedia.
- [ ] Monitoring aplikasi disiapkan.
- [ ] Deployment diuji di staging sebelum produksi.

Catat tanggal, penanggung jawab, versi commit, dan hasil pemeriksaan.
